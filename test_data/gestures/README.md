# Test data for `scripts/evaluate_gestures.py`

Add your own labeled photos here, one folder per class:

```
test_data/gestures/
    Thumb_Up/*.jpg
    Thumb_Down/*.jpg
    Victory/*.jpg
    Pointing_Up/*.jpg
    Fist/*.jpg
    Open_Palm/*.jpg
    ILoveYou/*.jpg

```

10-20 photos per class is enough for a meaningful first pass — vary lighting,
background, and hand position so the numbers reflect real conditions, not
just one clean shot repeated.

No images are checked in here on purpose — these are photos of *your* hand,
so it's your call whether to commit them to a public repo.
